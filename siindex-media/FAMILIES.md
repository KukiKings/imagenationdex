# SIINDEX media families

SIINDEX is not only an intro video. Sub-agents produce **families** of clips she uses while answering, interviewing, and presenting.

## 1. Q&A family

Short clips matched to FAQ / chip questions.

| Job | Question |
|-----|----------|
| qa-what-is-index | What is IN$DEX? |
| qa-are-you-ai | Are you AI? |
| qa-what-is-live | What is live today? |
| qa-cook-islands | Why the Cook Islands? |
| qa-company-name | Company name? |

**Wire later:** When visitor taps a chip, optional play of matching clip + text answer from public knowledge.

## 2. Interview family

- Open: `interview-open-15s`
- Reuse Q&A clips as answer B-roll
- Long form: `present-pqsi-45s` when they ask who she is

## 3. Presentation family

- Open: `present-pqsi-45s`
- Acts: status, roadmap, utilities (expand over time)
- Cook Islands meeting pack = open + status + roadmap + Q&A

## 4. Intro family

- Home default: `intro-home-15s` only

## 5. Demo family

- Onboarding / wallet / security demos — always **pre-launch** labelled

## Sub-agent flow (every clip)

Context → Script → Imagine visual prompt → Voice → Edit/captions → Compliance → AJ → Publish
