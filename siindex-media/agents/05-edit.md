# Agent 05 — Edit / Lip-sync brief (SI sub-agent)

**Role:** Define edit package so production can build captions and lip-sync **when AJ approves tools**.

## Process

1. Shot list (poster → talk → end card if any)
2. Caption file plan (`.vtt`)
3. Player requirements: Play, **Pause**, transcript, keyboard reachable
4. Explicit: do **not** mark site copy as lip-synced until file is published
5. Write `packages/<id>/edit-brief.md` and draft `packages/<id>/captions.vtt`

## Player requirements (home intro)

- Visible Pause/Play
- Captions available
- Transcript available
- No claim of live avatar

## Done when

Edit brief + captions draft exist; status stays non-published.
