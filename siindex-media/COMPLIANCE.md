# SIINDEX Media Compliance

Every package must pass this checklist before status can become `needs-aj`.

## Brand and identity

- [ ] Spoken and on-screen text leads with **IN$DEX** where the product is named
- [ ] SIINDEX described as **Synthetic Intelligence** / **SI** / **PQSI** only
- [ ] Never: AI, artificial intelligence, chatbot, assistant (except deliberate SI-vs-AI contrast if explicitly briefed)
- [ ] Legal stack only if the job is about company name: Image Nation DEX → Image Nation Decentralized Exchange → Image Nation DEx Limited
- [ ] Registration: **in progress** until certificate — never claim completed registration or government licence

## Facts

- [ ] $0.24 = founder-selected genesis / launch **reference only** — not a live market price
- [ ] 98/2 = permanent doctrine — not live smart-contract enforcement until verified deployed code
- [ ] Public pilot target 24 February 2027 = **target**, not guarantee of every feature
- [ ] Live vs not-live matches current public surface (no false “payments live”)
- [ ] Findex (if used): **Global Findex 2025**, **1.3 billion** without account — do not mix 2021 1.4bn as current figure

## Agency and Pacific story

- [ ] Pacific / Cook Islands subjects are **agents**, not passive rescue objects
- [ ] Prefer: she acts (scans, sale happens, returns to work) over technology-as-saviour close

## Accessibility

- [ ] Auto-advancing sequences >5s have a visible **Pause** (not only Skip)
- [ ] Controls have accessible names (`aria-label` where needed)
- [ ] Captions / transcript provided for spoken intro
- [ ] Honour `prefers-reduced-motion` where motion is decorative

## Publish gate

- [ ] Status is `needs-aj` only after compliance pass
- [ ] No write to `/videos/`, production HTML, or public social without AJ approval
- [ ] Lip-sync claimed on site only after approved file is deployed

## Forbidden without AJ

- Public media publish
- Voice/likeness clone activation beyond existing approved website TTS path
- HeyGen / avatar / lip-sync provider spend and publish
- Any financial, identity, or legal claim not already on the public living knowledge
