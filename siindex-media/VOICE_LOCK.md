# Media swarm — voice lock

All SIINDEX public videos must use the **same** voice identity as website TTS.

- Do not ship a new intro, Q&A clip, or interview open with a different speaker.
- Production packages reference `siindex-operating/VOICE_IDENTITY.md`.
- Lip-sync jobs use the approved voice; random Grok/Imagine defaults are not publishable without AJ check against website TTS.
- Package status stays `needs-aj` until voice match is verified by ear against imagenationdex.com chat replies.
