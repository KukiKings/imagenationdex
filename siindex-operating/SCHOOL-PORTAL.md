**Status:** Planned · not a live student system  
**Language:** English public UI  
**Gate:** AJ PROCEED per release

## Purpose

One entry for schools in Cook Islands and Pacific nations to:

1. Browse education tracks (business, language, stewardship, finance, courses, trades)  
2. Link learning progress to `yourname.IN$DEX` when issuance is live  
3. Parental view for under-18 (keys until 18)  
4. Teacher / mentor directory (later)
