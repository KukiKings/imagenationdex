## The loop (never optional)

```
Deep research (second brain · white paper · memory · live policy)
        ↓
Think / design (SIINDEX + tools as her limbs)
        ↓
Build
        ↓
Test what works (real surfaces, real HTTP, real dry-run)
        ↓
M2M / SI↔SI / SIINDEX→swarm discussion of results
        ↓
Learn
        ↓
Fix errors and issues in real time
        ↓
(repeat 24/7)
```

## Authority

| Layer | Does |

## Daily standard

1. Something is researched or verified every working cycle.  
2. Something is tested against live URLs or lab smoke.  
3. Something is built or fixed and written back (repo / memory / second brain).  
4. Failures are logged and re-entered into the loop — not left for “later sprint.”  
5. Public claims stay on living knowledge until AJ expands them.
