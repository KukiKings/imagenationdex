# P2.1 — needs-aj delivery (email → SMS)

**Status:** Wired in M2M  
**Law:** Every task asks AJ · no auto-approve  
**Priority:** **Email** (full packet) → **SMS** (short alert)

---

## What was built

| Piece | Path |
|-------|------|
| Notify module | `siindex-m2m/notify.mjs` |
| Outbox (always) | `siindex-m2m/outbox/` |
| Env example | `siindex-m2m/notify.env.example` |
| Runner hook | On `needs-aj`, runner calls `notifyNeedsAj` |

## Flow

```
Agent returns needs_aj
  → job.status = needs-aj
  → notify builds packet (NEEDS-AJ-FORMAT)
  → write outbox JSON (always)
  → SMS via Twilio if AJ_NOTIFY_SMS + Twilio env set
  → Email: packet in outbox + subject/body ready; set AJ_NOTIFY_EMAIL
     and send via Gmail/API/operator (see below)
  → AJ replies PROCEED | HOLD | REJECT | REVISE
  → node runner.mjs authorize <jobId>
```

## Commands

```bash
cd siindex-m2m
node notify.mjs test          # writes sample outbox packet
node runner.mjs tick          # on needs-aj, notifies
node runner.mjs authorize <id>
```

## Live email

1. Set `AJ_NOTIFY_EMAIL` to your inbox.  
2. Outbox files contain `email.subject` + `email.body`.  
3. Send with Gmail (draft/send) or any SMTP — swarm must not invent addresses.  
4. Optional: operator workflow copies outbox → send.

## Live SMS

Set `AJ_NOTIFY_SMS` (E.164) + Twilio SID/token/from. Without Twilio, SMS stays `outbox_only` / `not_configured` — packet still logged.
