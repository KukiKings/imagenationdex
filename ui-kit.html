UI Kit — Reference Only
How this doc was built: every token and component below was extracted directly from the real, live screens (founding-citizen.html, mission-ledger-dashboard.html, governance.html, history.html, citizen-profile.html) on 2026-08-21 — nothing here was invented. Where screens disagree with each other, that's flagged below instead of papered over. This file isn't wired to anything and isn't linked from the app nav; it's a reference doc for whoever's building the next screen, human or Claude.

Known drift (not yet reconciled): citizen-profile.html uses --text: #EAEAEA (not #F0F2FF) and adds a --border token others don't have. governance.html and history.html both name the base background --bg instead of --black, and use slightly different surface hex values (#10121A/#0E1019 instead of #12141F). None of this is broken — the screens still look right — but a new screen should follow the canonical set above, not copy an older file's variant.
Page shell
Every app screen (not marketing/landing pages) uses this exact structure — sticky topbar with back button, then a padded content area, capped at 430px on mobile.
body { max-width:430px; margin:0 auto; } .topbar { background:var(--surface); border-bottom:1px solid rgba(255,255,255,0.06); padding:14px 16px; display:flex; align-items:center; gap:12px; position:sticky; top:0; z-index:100; } .back-btn { width:36px; height:36px; border:none; background:var(--surface2); border-radius:10px; color:var(--text); font-size:18px; cursor:pointer; } .content { padding:16px; padding-bottom:40px; }
